# Was muss ich tun, um richtig loslegen zu können?

Du solltest die Teilprojekte mit etwas Basiswissen zu Docker, Maven und NPM ohne Komplikationen (auch innerhalb der IDE)
nutzen können. Merke Dir bitte die ungefähre Zeitspanne, die Du für das Setup benötigst und teile im Anschluss Deine
Erfahrungen.

Da sich in unserem Beratungs-Alltag die Laufzeitumgebungen in Abhängigkeit vom Projektkontext ändern können, bietet sich
die Nutzung von Tools zur Verwaltung an.

## Java

Sehr empfehlenswert ist SDKMAN!

Die Installation wird hier beschrieben: https://sdkman.io/install/

Für die Aktivierung der "richtigen" Java-Version musst Du dann noch im Backend-Verzeichnis (siehe 
https://sdkman.io/usage/#env-command): 

```bash
sdk env
```
